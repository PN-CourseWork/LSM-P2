## Quick Start

### Installation

This project uses [uv](https://docs.astral.sh/uv/) for dependency management.

1. **Install uv** :
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```

2. **Install dependencies**:
   ```bash
   uv sync
   ```
